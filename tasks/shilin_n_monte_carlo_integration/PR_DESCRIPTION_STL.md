# Шилин Никита. Технология STL. Вычисление многомерных интегралов методом Монте-Карло. Вариант 12.

## Описание

**Задача:** Вычисление многомерных интегралов методом Монте-Карло.
**Вариант:** 12
**Технология:** STL

### Входные данные

Параметры интегрирования, заданные структурой:

- `lower`, `upper` — `std::vector<double>`, нижние и верхние границы интегрирования по каждой оси;
- `n` — `int`, число точек квази-случайной выборки;
- `func_type` — тип подынтегральной функции из заданного набора (`FuncType`).

### Выходные данные

Приближённое значение интеграла (`double`).

### Описание реализации

Была реализована STL-версия алгоритма вычисления многомерных интегралов методом квази-Монте-Карло.

Алгоритм состоит из двух основных этапов:

1. **Генерация квази-случайных точек**
   Для каждого индекса `i` из диапазона `[0, n)` координаты точки вычисляются по формуле Кронекера в замкнутой форме:
   `x[d] = frac(0.5 + (i+1) * alpha[d])`, где `alpha[d]` — дробная часть квадратного корня из простого числа.
   Затем точка отображается на прямоугольную область интегрирования.

2. **Суммирование значений подынтегральной функции**
   Для каждой сгенерированной точки вычисляется значение подынтегральной функции и суммируется.
   Итоговый результат: `volume * sum / n`, где `volume` — произведение длин рёбер области.

3. **Использование STL**
   Распараллеливание выполнено средствами стандартной библиотеки C++:
   - диапазон индексов `0 .. n-1` задаётся через `std::views::iota`;
   - параллельное суммирование реализовано через `std::transform_reduce` с политикой выполнения `std::execution::par` и `std::plus<>()`;
   - для переиспользования памяти между итерациями в каждом потоке используется `thread_local std::vector<double>` для координат точки.

   Так как вычисления для каждой точки независимы, такой подход позволяет безопасно распараллелить основной вычислительный цикл.
